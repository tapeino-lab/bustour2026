# あおやまなしバスタワー2026

スマホ向けの、どうぶつを積み上げる物理パズル（一人用）。

公開先: https://tapeino-lab.github.io/bustour2026/

## 遊び方

- 指で左右に動かし、離すと落ちる。下の「かいてん」ボタンか、動かしている途中にもう1本の指で画面に触れると45°回転。
- PC では右クリックでも回転（左ボタンで動かしながら右クリックでも回る）。
- 動かしている途中に「かいてん」ボタンの上で指を離すと、落とさずにキャンセル。
- 出る順番は「周」ごと：各周はかならずバスから始まり、そのあと どうぶつ18種類（色違いも別々に1つずつ）がシャッフルされた順に1回ずつ出る。出しきったら次の周（またバス→シャッフルし直し）。ゲームごとに1周目からやり直し。
- 落ちていて何にも触れていないオブジェクトが画面の下端に届いたらゲームオーバー。スコアは積めた数。

## 開発

```sh
npm ci
npm run dev    # 開発サーバー
npm run lint   # ESLint と型チェック
npm test       # Vitest
npm run build  # dist/ に出力
```

main に push すると GitHub Actions（.github/workflows/deploy.yml）で GitHub Pages に公開されます。

物理演算は planck.js（Box2D 系）。ウーパールーパーだけは頭・胴・しっぽの3つの体をやわらかい溶接（バネ）でつないだ「やわらかい」どうぶつ。背景の富士山は遠景として、カメラの3割の速さでスクロールする。

### 更新の反映

ビルド時に `version.json`（package.json のバージョン）を一緒に公開します。遊んでいる端末は1分ごと（とアプリに戻ったとき）にこれを確認し、新しいバージョンが出ていれば、自然なタイミングでだけ読み込み直します：ゲームオーバー後の「もういちど」、まだ1個も落としていないゲームの始まり（指が触れておらず、ほかの画面も開いていないとき）、結果画面のままアプリに戻ってきたとき。ゲームの途中では読み込み直しません。`?v=バージョン` を付けてキャッシュを避け、`?admin=1` などはそのまま残します。

## 顔写真（参加コードで見られる）

顔写真は**このリポジトリには入れません**（公開リポジトリのため）。Firebase（Firestore）に保存し、参加コードを入力した端末だけが見られます。

- 端末は匿名ログインし、正しい参加コードを入れると `members/{uid}` が作られてメンバーになります（判定は Firestore ルール側。コードの答えはゲームのコードに含まれません）。
- 顔写真は `faces/{どうぶつID}` に 160×160 の JPEG（data URL）で保存。登録と表示は別で、管理画面の「ひょうじ」をオンにした写真だけがゲームに出ます（メンバーが読めるのは表示オンの写真だけ。ルールで制限）。管理者だけが書けます。
- 管理者は `?admin=1` を付けて開くと「かお とうろく」画面と確認用の表示が出ます（付けなければ管理者の端末も一般ユーザーとして動きます）。表示される ID を Firestore の `admins/{ID}` に登録すると、写真を登録できます。
- ルールは `firestore.rules`。`npm run test:rules` でエミュレーター上のテストを実行（Java が必要）。
- Firebase の設定値は GitHub Secrets（`FIREBASE_API_KEY` / `FIREBASE_AUTH_DOMAIN` / `FIREBASE_PROJECT_ID` / `FIREBASE_APP_ID`）からビルド時に渡します。未設定ならダミーの顔で動きます。
- ローカルでエミュレーターを使う場合は `VITE_FIREBASE_EMULATOR=1` と各 `VITE_FIREBASE_*` を付けて `npm run dev`。

## ランキング（メンバーのみ）

- 「たかさ」（積み上がって止まった最高の高さ）と「こすう」（積めた数）の2つ。ゲームオーバー画面に左右に並べて、それぞれ上位10人を表示。
- 人が少ないうちは、3個程度のダミー（灰色の文字）が混ざって並ぶ。ダミーはゲーム内の `src/ranking.ts` の `DUMMY_ROWS` にあり、Firestore には入っていない。消すときはそこを空にする。
- `scores/{uid}` に 1端末1件（名前・最高個数・最高高さ）。自己ベストを超えたときだけ更新でき、下がる書き込みはルールで拒否。
- 名前はひらがな1〜3文字（ー可）。画面内の50音キーボード（゛ ゜ 小 ー と、名前の右に けす）で入力するので、ひらがな以外・4文字以上は入らない。チェックは画面と Firestore ルールの両方。「なまえを かえる」であとから変更できる。
- 初めて自己ベストを出したときに名前を聞く。「なまえを かえる」で変更可。
- 記録には、その記録を出したゲームで最後に止まったときのタワー（各オブジェクトの種類・位置・角度、`src/tower.ts`）を保存。こすう用 `towerCount` とたかさ用 `towerHeight`。物理演算は使わずにそのまま描くので、物理の設定を変えても見た目は変わらない（オブジェクトの形が変わると変わる）。
- 上位3位はサムネイル付き。ほかは「みる」から。ゲームオーバー画面の「じぶんの タワーを みる」で今回のタワーも見られる。

どうぶつの ID は `src/pieces.ts` を参照。

## 音

- 「つぎ」の下に「BGM」「おと」の切り替え。起動するたびに両方オフ。
- 効果音はファイルを使わずブラウザ内で合成（回転・落下・着地・登場・ゲームオーバー・自己ベスト）。BGM は効果音より少し小さめ。
- BGM は著作権のある曲を想定しているため**リポジトリには入れない**。管理者が `?admin=1` の画面から mp3（700KB まで）を登録すると Firestore の `media/bgm` に保存され、メンバーだけが聞ける。オンにしたときに初めてダウンロードする。
